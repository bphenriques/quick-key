# Introduction

quick-key is a keyboard menu for [Quickshell](https://quickshell.org) whose rows show live state beside labels that never change, and where the key path you press (`a 2`) is the binding you script. One key opens it. A pop-up shows changes to the volume, the microphone, brightness, the keyboard layout and keep-awake.

It is a menu first. It sits beside the bar or shell you have and replaces neither. Plugins add the rest, most of them a command and a few lines of config (see [Recipes](recipes.md)).

It runs without a config; `config.json` changes only what you set (see [Configuration](configuration.md)).
